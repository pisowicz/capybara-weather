# Capybara Weather Sticker Pack

Eight transparent-background stickers rendered from the app's hand-drawn
scenes (original art, no licensing constraints — use them anywhere).

## Ship them as an iMessage sticker pack

1. On a Mac: Xcode → File → New → Project → **Sticker Pack App**.
2. Drag every `capy-*.png` from this folder into the `Stickers.xcstickers`
   asset catalog.
3. Set the app name (e.g. "Capybara Weather Stickers"), pick an icon
   (use `../icons/icon-512.png`), and submit via App Store Connect.
   Sticker packs need no code at all.

They also work as Telegram/WhatsApp sticker sources, Discord emoji
material, or stream overlays.
